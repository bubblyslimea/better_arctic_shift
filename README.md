# better arctic shift

keep a thread's words, and the changes that follow

made for riri's reddit scrapbook, with archived text, dated removal observations, and the surrounding conversation kept together

- preserve captured wording when a comment is later removed
- revisit watched threads and check every saved comment id
- search old and current text with parents and replies included
- keep unresolved ids and stale statuses visible
- read compressed dumps without damaging split Unicode characters
- export a ZIP that opens in the scrapbook

[setup, commands, and technical details](TECHNICAL_DETAILS.md)

based on [Arctic Shift by ArthurHeitmann](https://github.com/ArthurHeitmann/arctic_shift)
the original [readme and credits](UPSTREAM.md), [dataset links](download_links.md), [collection notes](file_content_explanations.md), and [hosted API documentation](api/README.md) are preserved
